EasyAdmin基于ThinkPHP5.1后台管理框架
===============

EasyAdmin对PHP的依赖注入和切面编程进行了封装，其主要特性包括：

 + 支持动态代理
 + 支持AOP切面
 + 支持注入依赖

> EasyAdmin的运行环境要求PHP7.4及以上。

## 安装

使用git安装

~~~
git clone https://gitee.com/wansxlysys/easyadmin.git
~~~

启动服务

~~~
cd easyadmin
php think run
~~~

然后就可以在浏览器中访问

~~~
http://localhost:8000
~~~
